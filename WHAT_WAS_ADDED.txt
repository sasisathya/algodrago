🌳 TREE ALGORITHMS (4 algorithms)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File: src/data/treeAlgorithms.ts

✓ Inorder Traversal (Left-Root-Right)
  - Time: O(n)
  - Space: O(h) - recursive call stack
  - Best for: BST sorted output

✓ Preorder Traversal (Root-Left-Right)
  - Time: O(n)
  - Space: O(h)
  - Best for: Copying trees

✓ Postorder Traversal (Left-Right-Root)
  - Time: O(n)
  - Space: O(h)
  - Best for: Deleting trees

✓ Level Order Traversal (BFS)
  - Time: O(n)
  - Space: O(w) - max width
  - Best for: Finding nodes at specific levels

New Data Structures:
  - TreeNode (value, left, right, height, balanceFactor)
  - TreeStep (tree state, highlighted node, traversal order)


🔀 DIVIDE & CONQUER ALGORITHMS (3 algorithms)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File: src/data/divideConquerAlgorithms.ts

✓ Tower of Hanoi
  - Time: O(2^n) - exponential
  - Space: O(n) - recursion depth
  - Shows: Divide → Conquer → Combine phases
  - Difficulty: Beginner (educational)

✓ Fibonacci with Memoization
  - Time: O(n) - with memoization (vs O(2^n) without)
  - Space: O(n) - memo storage
  - Shows: Recursion tree + memoization benefits
  - Difficulty: Beginner

✓ Strassen's Matrix Multiplication
  - Time: O(n^2.81) - faster than O(n^3)
  - Space: O(n^2) - temporary matrices
  - Shows: Recursive matrix operations
  - Difficulty: Advanced

New Data Structures:
  - DivideConquerStep (operation, state, recursion depth)
  - Phase tracking: 'divide' | 'conquer' | 'combine'
